# Тренировочная Булочек — Telegram Mini App

Приложение для бота [@Nina_fitbody_bot](https://t.me/Nina_fitbody_bot): тренировки в зале и дома,
гимнастика, МФР, отметки о выполнении и дневник веса с графиком.

Адрес: https://gusina34.github.io/fitness-bot-webapp/

## Как поменять упражнения, тексты и видео

Всё содержимое лежит в одном файле: [`data/workouts.js`](data/workouts.js).
Откройте его на GitHub → значок карандаша → внесите правки → **Commit changes**.
Через 1–2 минуты приложение обновится само.

Названия упражнений взяты со схем бота в Leadteh. Проверьте их и допишите подходы (`sets`),
технику (`description`) и видео (`video`).

### Видео

Видео, загруженные в Leadteh, приложение показать не может: у них нет публичной ссылки. Самый простой способ:
1. Создайте **закрытый** Telegram-канал и выложите туда видео упражнений (по одному посту на видео).
2. Скопируйте ссылку на пост (`https://t.me/c/…/12`) и вставьте её в поле `video` упражнения.

Кнопка «Смотреть видео» откроет пост прямо в Telegram. Клиенты должны состоять в канале,
поэтому ссылку-приглашение можно выдавать после оплаты.

## Подключение к боту в Leadteh

1. В главном меню бота (после «Условия» → Yes, чтобы видели только оплатившие) добавьте кнопку
   типа **Web App** со ссылкой `https://gusina34.github.io/fitness-bot-webapp/`.
2. Можно сделать Mini App основным приложением бота: @BotFather → `/mybots` → бот → Bot Settings →
   Configure Mini App. Тогда ссылки вида `https://t.me/Nina_fitbody_bot/app?startapp=weight`
   будут открывать сразу дневник веса, а `?startapp=gym-1` — нужную тренировку.

## Дневник веса

Замеры хранятся в Google Таблице: в той же, куда пишет бот (столбцы `telegram_id | date | weight`).
Настройка: инструкция в начале [`apps-script/Code.gs`](apps-script/Code.gs), затем вставьте ссылку `/exec`
в `config.googleScriptUrl` в `data/workouts.js`.

Отметки о выполненных тренировках хранятся в облаке Telegram у каждого клиента и не требуют настройки.

## Ограничения

Само приложение не проверяет подписку: доступ ограничивается тем, что кнопку видят только
клиенты с тегом оплаты в Leadteh. Ссылку на страницу при этом можно переслать.
Платный контент (видео) защищён закрытым каналом.
