# Видео для сторис

Сюда кладутся короткие зацикленные ролики упражнений для тренировки в формате сторис.

- Вертикальные 9:16, 5–10 секунд, **без звука**.
- Формат **.mp4** (H.264), 720×1280, размер файла — до 2–3 МБ.
- Имя файла латиницей без пробелов: `glute-bridge.mp4`, `pull-ups.mp4`.
- В `data/workouts.js` у упражнения: `loop: 'videos/glute-bridge.mp4'`.
